# UrbanRide Rentals

UrbanRide Rentals is a premium full-stack vehicle rental platform with a modern React + Vite frontend and a lightweight Node.js backend. It includes public fleet discovery, customer booking flows, UPI QR payment instructions, support tickets, and staff operations.

## Highlights

- Premium SaaS-style landing page with glassmorphism, responsive layouts, and dark mode
- Framer Motion interactions across hero, cards, modals, and section reveals
- Integrated `ElectricBorder` component for animated premium spotlight panels
- Public fleet discovery with live filters for city, category, fuel, seating, and availability
- Customer registration, login, bookings, invoices, and reviews
- UPI QR payment instruction flow backed by the Node API
- Staff dashboard for booking transitions, vehicle status changes, support tickets, and inventory creation
- Deployable Docker setup and GitHub Codespaces support

## Tech stack

- Frontend: React 19, Vite 8, Framer Motion
- Backend: Node.js native `http` server
- Persistence: local JSON data store at `data/store.json`

## Local development

Install dependencies:

```bash
npm install
```

Run the frontend and backend together:

```bash
npm run dev
```

This starts:

- Vite frontend at `http://127.0.0.1:5173`
- Node API at `http://127.0.0.1:3000`

The Vite dev server proxies `/api` requests to the Node backend.

## Production build

Build the React frontend:

```bash
npm run build
```

Start the production server:

```bash
npm start
```

The Node server will serve the generated `dist/` frontend and all `/api/*` routes from the same process.

## Environment variables

Set these before production startup, especially for staff access:

- `ADMIN_EMAIL`: staff login email
- `ADMIN_PASSWORD`: staff login password
- `ADMIN_NAME`: optional staff display name
- `ADMIN_PHONE`: optional staff phone number
- `COMPANY_NAME`: optional company name override
- `SUPPORT_PHONE`: optional support phone override
- `SUPPORT_EMAIL`: optional support email override
- `UPI_ID`: payment UPI ID
- `CITY_COVERAGE`: comma-separated city list
- `HOST`: bind host, defaults to `0.0.0.0`
- `PORT`: server port, defaults to `3000`

Example:

```bash
export ADMIN_EMAIL=ops@yourdomain.com
export ADMIN_PASSWORD='replace-with-a-strong-password'
export ADMIN_NAME='UrbanRide Operations'
export SUPPORT_EMAIL=support@yourdomain.com
export SUPPORT_PHONE='+91 98765 43210'
export UPI_ID='harsh97830544@oksbi'
npm run build
npm start
```

## Deployment

### Docker

Build the image:

```bash
docker build -t urbanride-rentals .
```

Run the container:

```bash
docker run -p 3000:3000 \
  -e ADMIN_EMAIL=ops@yourdomain.com \
  -e ADMIN_PASSWORD='replace-with-a-strong-password' \
  -e UPI_ID='harsh97830544@oksbi' \
  urbanride-rentals
```

### GitHub Codespaces

1. Open the repository on GitHub.
2. Click `Code` -> `Codespaces` -> `Create codespace on main`.
3. In the terminal, install dependencies if needed:

```bash
npm install
```

4. Start development:

```bash
npm run dev
```

5. Open the forwarded Vite port when prompted.

## Notes

- `data/store.json` is created automatically and is intentionally ignored by Git.
- Historic seed reviews and bookings are retained for a populated storefront, but the previous public demo credentials are no longer exposed.
- The current QR image is rendered through `api.qrserver.com`. For regulated production payment flows, replace this with a managed payment provider integration.
- The backend still uses SHA-256 for simplicity. For higher-security production deployments, migrate password hashing to bcrypt or Argon2.
